# RULE_MEMBER / ЗАПОМНИ

## Описание
Анализ последнего промпта, который потребовал нескольких итераций на исправление.  
Установить корневые причины многократных правок и задокументировать правила, чтобы в будущем аналогичные задачи решались с первого раза.

## Алгоритм
1. Определить последний промпт пользователя, который вызвал >1 цикла правок
2. Для каждой итерации: что было сделано, почему не сработало, что должно было быть сделано иначе
3. Определить корневые причины:
   - Неполное понимание требования?
   - Отсутствие тестовой среды?
   - Незнание особенностей платформы (WPF, BAT, кодировки)?
   - Нет проверки регрессии?
   - Изменение нескольких взаимосвязанных частей одновременно?
4. Записать правила предотвращения в `AGENTS.md` (раздел Bug-037+) и/или в `rules/`
