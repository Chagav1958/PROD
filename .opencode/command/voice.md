# ГГ / VV

Запусти скрипт `scripts\voice-prompt.ps1` из корня проекта. Этот скрипт:
1. Выводит приглашение нажать Enter для начала записи
2. После Enter — начинает запись с микрофона
3. После второго Enter — останавливает запись и распознаёт речь (faster-whisper, модель base)
4. Выводит распознанный текст и копирует его в буфер обмена

Если скрипта нет — сообщи что `scripts\voice-prompt.ps1` не найден.

Пользователь должен запускать команду в ОТДЕЛЬНОМ окне PowerShell (через OpenCode bash передать Enter невозможно).
