# FIXSHOW

Запусти скрытно (антивирус): `powershell -NoProfile -File scripts\Launch-Hidden.ps1 -Script "Show-OpStatus.ps1"`. Скрипт открывает WPF-окно с таблицей всех 18 операций, их статусами (EDIT/FIXED) и кнопками для смены статуса. Если скрипта нет — сообщи что файл не найден.
