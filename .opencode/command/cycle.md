# ЦИКЛ <номер_ОП>

## Описание
Автоматический цикл исправления ошибок для операции GUI.  
Запускает указанную операцию с последними сохранёнными параметрами, проверяет протокол (`temp/last_output.log`), и если есть ошибки — исправляет код и повторяет (макс. 100 итераций или до устранения ошибки).

## Параметры
- `<номер_ОП>` — номер операции в выпадающем списке GUI (1-based)

## Алгоритм
1. Определить номер операции (параметр) и найти её `Name` в массиве `$operations` (Prod-GUI.ps1)
2. Собрать последние использованные параметры для этой операции (из `config/`, `history/` или OUT)
3. Запустить скрипт `scripts/auto_fix_loop.ps1 -OpNumber <номер>`
4. Прочитать `temp/last_output.log`
5. Если есть ошибка (VSS недоступен, исключение, таймаут) — проанализировать причину, исправить код в `Prod-GUI.ps1` и перейти к шагу 3
6. Если ошибок нет — сообщить об успехе

## Завершение
- **Успех:** `"SUCCESS: Операция выполнена"` или `"SUCCESS: Операция эмулирована"` — ошибок нет, цикл завершён
- **Лимит:** `"Limit (100)"` — достигнут лимит итераций
- **Ошибка скрипта:** скрипт `auto_fix_loop.ps1` не найден или не может быть запущен

## Таймауты
- Некоторые операции (VSS, SQL Export) могут выполняться >2 минут
- Команда должна запускаться с таймаутом не менее 300000ms (5 минут)
- Внутренний таймаут скрипта: 180000ms (3 минуты) для обычных операций, infinite для диалоговых (ОП 18)
