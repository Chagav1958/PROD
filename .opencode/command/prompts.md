# /prompts / ПРОМПТ

1. Сохрани ВСЕ промпты пользователя из текущей сессии (из conversation history)
   в файл `temp/user_prompts.log` в формате:
   ```
   [дд.мм.гггг, чч:мм:сс]
   полный текст промпта
   ============================================================
   ```
   - Дата/время — из времени получения промпта или текущего, если неизвестно.
   - Проверь по тексту, что промпт ещё не сохранён (нет дубликатов).
   - Сохраняй ТОЛЬКО промпты длиной более 20 символов.
   - Сохраняй текст МАКСИМАЛЬНО ПОДРОБНО (всё сообщение целиком).

2. После сохранения — проверь, что в файле `temp/user_prompts.log` есть записи
   за последние 2 дня. Если нет или неполно — восстанови:
   - Найди `user_prompts.log` в `archives\prompts\prompts_archive.log`
   - Проверь снапшоты в `archives\*\*` на наличие файлов `user_prompts.log`
   - Скопируй найденные записи в `temp/user_prompts.log` (без дубликатов)

3. Запусти скрытно (антивирус): `powershell -NoProfile -File scripts\Launch-Hidden.ps1 -Script "Show-Prompts.ps1"`

4. Скажи пользователю что окно открыто.
5. Если скрипта нет — сообщи что файл не найден.
