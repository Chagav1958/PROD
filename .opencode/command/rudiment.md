# РУДИМЕНТ <имя_объекта | ALL>

## Описание
Анализ скриптов PowerBuilder или SQL-объектов на предмет рудиментов — участков кода, оставшихся от предыдущих версий, но теперь не работающих никогда. Включает:
- Устранение дублирования кода
- Поиск неработающих ссылок (на удалённые объекты, функции, переменные)
- Исправление устаревших имён
- Удаление мёртвого кода (dead code)

## Параметры
- `<имя_объекта>` — имя ДО (диалогового окна) или другого объекта. РУДИМЕНТ проводится только с указанным объектом и связанным с ним функционалом
- `ALL` — обработка по всем объектам проекта и по всему функционалу

## Алгоритм
1. Определить область обработки (один объект или ALL)
2. Для каждого объекта:
   a. Прочитать исходный код (.sr* для PB, .sql для SQL)
   b. Проанализировать структуру: найти все объявления переменных, функций, событий, элементов управления
   c. Найти неиспользуемые переменные (объявлены, но нигде не вызываются)
   d. Найти дублирующиеся участки кода (одинаковые блоки >3 строк)
   e. Найти ссылки на несуществующие объекты/функции (broken references)
   f. Найти устаревшие имена (функции/переменные, переименованные в новой версии)
   g. Сформировать отчёт: объект | строка | тип рудимента | рекомендация
3. Вывести результаты в виде таблицы (DataGrid) с колонками: Объект, Строка, Тип рудимента, Описание, Рекомендация
4. Предложить исправления (с возможностью подтверждения каждого изменения)

## Результат
- Таблица найденных рудиментов
- При подтверждении — исправленный код
- Если рудиментов не найдено — сообщение "Рудиментов не обнаружено"
