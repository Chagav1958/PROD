# Краткое руководство по шаблону техспеки AIS

## Структура файла

```
techspec-BSI-XXXX.md
├── 1. КОНТЕКСТ           — проблема, связи, источники
├── 2. AS-IS              — текущее состояние (объекты, данные, логика)
├── 3. TO-BE              — целевое состояние (блоки, DDL, код)
├── 4. ЗАТРОНУТЫЕ СИСТЕМЫ — влияние на другие системы
├── 5. РИСКИ              — риски и снижение
├── 6. КРИТЕРИИ ПРИЁМКИ   — продуктовые и технические критерии
├── 7. ДЕКОМПОЗИЦИЯ       — US и подзадачи
└── 8. ПРИЛОЖЕНИЯ         — схемы, примеры, скриншоты
```

## Порядок заполнения

### Шаг 1: Контекст
- Заполните задачу (SYBASE-XXXX / BSI-XXXX)
- Укажите связи и источники

### Шаг 2: AS-IS
- Найдите объекты через `ais-objects_search_objects`
- Прочитайте структуру таблиц через `ais-objects_get_object`
- Опишите текущую логику

### Шаг 3: TO-BE
- Разбейте на логические блоки
- Для каждого блока: объекты, DDL, код
- Используйте pseudocode для PB

### Шаг 4: Остальные секции
- Заполните затронутые системы
- Оцените риски
- Запишите критерии приёмки
- Создайте декомпозицию

## Интеграция с инструментами

### Поиск объектов
```
ais-objects_search_objects(query="имя объекта")
ais-objects_get_object(name="имя объекта", src="current")
```

### Сохранение знаний
```
ais-catalog_save_knowledge(text="описание", tags="теги")
```

### Jira
- Ссылка на задачу в шапке
- US и подзадачи → SYBASE-XXXX

## Примеры

### Пример блока DDL
```sql
-- Добавление колонки
ALTER TABLE ais_cat_pdf_location 
ADD act_date_mode char(1) null
GO
```

### Пример блока PB
```powershell
// ue_toolbar (кнопка «Обновить»)
if dw_list.ModifiedCount() > 0 then
    if MessageBox("Внимание", "Сохранить?", 
                  Exclamation!, YesNo!, 2) = 1 then
        dw_list.Update()
    end if
end if
dw_list.Retrieve()
```
