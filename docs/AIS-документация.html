8. Кодировка файлов

Тип файлаКодировкаBOMПоследствия ошибки
.ps1UTF-8с BOMPS 5.1 читает как CP1251 → кракозябры
.json / .jsoncUTF-8без BOMOpenCode не грузит плагины (Bug-044)
.sqlWindows-1251нет—
.batWindows-1251нет—
.mdUTF-8без BOM—
BOM для .ps1: PowerShell 5.1 на русской Windows требует BOM. Без BOM читает как CP1251 → все строковые литералы с кириллицей ломаются.

8.1. Запуск PowerShell из bash tool

ВСЕГДА:   powershell -NoLogo [-File script.ps1]
НИКОГДА:  -NoProfile (Bug-046: ломает UTF-8 вывод)
