Руководство пользователя ДО TaskPlan

Назначение

ДО TaskPlan — диалоговое окно управления планами объёмных задач. Позволяет создавать задачи, отслеживать этапы, переключаться между LLM, готовить брифы для дорогих моделей.

Запуск ДО

Команда u{FFFD}TaskPlu{FFFD}


# В PowerShell или в строке команд OpenCode
TaskPl

Или напрямую:


powershell -NoLogo -File scripts\Show-TaskPlanGUI.ps1 -TaskName SYBASE-12345

При запуске ДО открывается в центре экрана. Окно без рамки, с прозрачностью, можно перетаскивать за заголовок.

Цветовая маркировка строк

  • u{FFFB}Зелёныйu{FFFB} u{FFFD}[x] готовоu{FFFD} — этап выполнен
  • u{FFFB}Жёлтыйu{FFFB} u{FFFD}[~] в работеu{FFFD} — этап в процессе
  • u{FFFB}Красныйu{FFFB} u{FFFD}[!] отложеноu{FFFD} — этап отложен на дорогую LLM
  • u{FFFB}Серыйu{FFFB} u{FFFD}[ ] не начатоu{FFFD} — этап не начат

Прогресс-бар

  • Показывает процент выполнения (готово / всего)
  • Обновляется при нажатии кнопки «⟳ Обновить»
  • Автоматически обновляется после операций на вкладке «Управление»

15 тестов

  1. Создание плана
  2. Чтение плана (state)
  3. Установка статуса wip
  4. Проверка статуса wip
  5. Установка статуса done
  6. Поиск следующего этапа
  7. Добавление этапов
  8. Проверка добавленных этапов
  9. Синхронизация JSON
  10. Просмотр плана (show)
  11. Подготовка брифа
  12. Удаление тестового плана
  13. Запуск GUI
  14. Поиск окна GUI (Automation)
  15. Закрытие GUI

Советы и рекомендации

  1. u{FFFB}Всегда указывайте LLMu{FFFB} при установке статуса — это сохраняет историю исполнителей.
  2. u{FFFB}Используйте «|Кем»u{FFFB} в этапах — тогда при создании плана сразу видно, кто будет выполнять.
  3. u{FFFB}Бриф перед дорогой LLMu{FFFB} — всегда готовьте бриф через «Подг. бриф», это экономит токены.
  4. u{FFFB}Синхронизация JSONu{FFFB} — если ДО показывает устаревшие данные, нажмите «Синхр. JSON».
  5. u{FFFB}Проверяйте тестыu{FFFB} — перед важными изменениями запускайте тесты на вкладке «Тесты».
