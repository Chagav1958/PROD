Контекст

Проект u{FFFB}AIS Release Preparationu{FFFB} — внутренний инструмент для подготовки релизов страхового продукта "Ренессанс". Инструмент автоматизирует сравнение SQL-объектов, выгрузку из PowerBuilder, работу с Jira/RFC и контроль версий (VSS). Проект написан на PowerShell 5.1, Python 3.12 и BAT-скриптах.
