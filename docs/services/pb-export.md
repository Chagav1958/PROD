# PB Export — сервис выгрузки PowerBuilder

> **Версия:** 1.1 от 01.09.2026 (добавлен раздел «7. Тестирование»)
> **Родительский том:** [Главный том документации](../master-index.md)

---

## 1. Назначение

Сервис выгрузки объектов PowerBuilder из PBL-файлов в текстовый формат (.sru, .srw, .srd) через утилиту pbldump.

**Файлы:**
- `scripts\Export-PB.ps1` — основной скрипт выгрузки (31 библиотека, 2617 объектов)
- `scripts\Extract-PbSrw.ps1` — извлечение .srw (Window)
- `scripts\Extract-PbSru.ps1` — извлечение .sru (UserObject)
- `scripts\Extract-PbRest.ps1` — извлечение остальных (.srd, .srm, .srs)
- `scripts\Extract-PbMetadata.ps1` — извлечение метаданных
- `tools\pbldump-1.3.1stable\PblDump.exe` — утилита экспорта

---

## 2. Процесс выгрузки

```
PBL-файлы (C:\Work\gold\*.pbl)
    ↓ pbldump
.sr* файлы (PB_Current\библиотека\*.sr*)
    ↓ Convert-ExportEncoding.ps1
UTF-8 с BOM, CRLF
```

---

## 3. Параметры МОРДА2 (ОП5)

| Параметр | Значение |
|----------|----------|
| Source | Current (C:\Work\gold) / Main (C:\SRC125\gold) |
| TaskName | Имя задачи Jira (опционально) |

---

## 4. Библиотеки (31 шт.)

`golden_subject`, `golden_rule`, `golden_correct`, `golden_...` — набор библиотек страхового продукта.

---

## 5. Кодировка

| Этап | Кодировка |
|------|----------|
| PBL (исходный) | ANSI (CP1251) |
| .sr* после pbldump | CP1251 / UTF-16 |
| .sr* после конвертации | **UTF-8 с BOM, CRLF** |

---

## 6. Экономическая выгода

- **Массовая выгрузка:** 2617 объектов за ~5 минут (ручной: ~6 часов)
- **Автоматическая кодировка:** нормализация CP1251→UTF-8 без ручного вмешательства
- **Инкрементальная:** выгрузка только объектов конкретной задачи
