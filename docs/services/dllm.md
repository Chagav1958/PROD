# DLLM — Диалоговое окно управления LLM-моделями

> **Версия:** 1.0 от 07.08.2026
> **Родительский том:** [Главный том документации](../master-index.md)

---

## 1. Назначение

DLLM (Диалоговое окно LLM) — WPF-интерфейс для просмотра, управления и тестирования языковых моделей, подключённых через провайдеры OpenCode.

**Файл:** `scripts\Show-LLMs.ps1` (1625 строк)

---

## 2. Возможности

- **Список моделей** — таблица всех LLM с полями: название, доступность, рейтинг PB/SQL, цена, контекст
- **Сортировка и фильтрация** — по цене, интеллекту, рассуждениям, скорости
- **Кнопка «Проверить все»** — автоматическая проверка доступности всех моделей через API
- **Смена текущей модели** — выбор основной и малой моделей для OpenCode
- **Статистика** — счётчики: всего, работоспособно, недоступно
- **Process-ключи** — отображение предупреждений об API-ключах из process environment

---

## 3. Провайдеры (из opencode.jsonc)

| Провайдер | Тип | Моделей |
|-----------|-----|---------|
| RouterAI | основной, платный | 6 (Claude, GPT, DeepSeek, Gemini) |
| Ollama | локальный, бесплатный | 2 (Qwen, DeepSeek Coder) |
| Yandex GPT | отключён | 1 |
| Anthropic | отключён | 1 |

---

## 4. Критерии оценки моделей

| Параметр | Шкала | Описание |
|----------|-------|----------|
| PB Rating | 1-11 | Качество анализа PowerBuilder-кода |
| SQL Rating | 1-11 | Качество анализа SQL/Sybase |
| Cost | $/токен | input × output |
| Context | токенов | Максимальный размер контекста |
| Reasoning | bool | Поддержка рассуждений |
| Tool Call | bool | Поддержка вызова инструментов |
| Speed | строка | Оценка скорости ответа |

---

## 5. Экономическая выгода

- **Быстрый выбор модели:** вместо ручного редактирования opencode.jsonc — один клик
- **Экономия токенов:** автоматический выбор дешёвой модели для простых задач
- **Мониторинг доступности:** кнопка «Проверить все» экономит ~10 минут ручной проверки
