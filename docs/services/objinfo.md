# ObjectInfo — справочник объектов PB и SQL

> **Версия:** 1.0 от 07.08.2026
> **Родительский том:** [Главный том документации](../master-index.md)

---

## 1. Назначение

ObjectInfo — WPF-приложение для просмотра справочной информации по объектам PowerBuilder и SQL: структура, зависимости, анализы, свойства.

**Файлы:**
- `scripts\Show-ObjectInfo-GUI.ps1` — основное окно
- `scripts\Show-ObjectInfo.cs` — C# backend (парсинг, поиск, кодировки)
- `bin\Show-ObjectInfo.bat` — лаунчер

---

## 2. Возможности

| Функция | Описание |
|---------|----------|
| **Поиск объектов** | По имени, типу, библиотеке |
| **Просмотр структуры** | Параметры процедур, колонки DataWindow, свойства |
| **Граф зависимостей** | Кто вызывает объект / кого вызывает объект (глубина 1-3) |
| **Сравнение Main/Current** | MD5-хеши, размеры, даты модификации |
| **Анализы** | Поиск по тексту сохранённых анализов (FTS5) |
| **Кодировка** | Автоопределение UTF-8/CP1251/UTF-16 по BOM |

---

## 3. Типы зависимостей

| Тип | Пример |
|-----|--------|
| `calls` | `w_policy → uf_get_entity` |
| `sql_ref` | `w_policy → usp_policy_select` |
| `dddw` | `dddw_insure_kind` |
| `contains` | `w_main → u_tab_policy` |
| `inherits` | `w_child ← w_base` |

---

## 4. База данных

- SQLite `objects.db` — 2473 PB + 2243 SQL объекта
- Импорт из `PB_Current`, `PB_Main`, `BD\dev_golden`, `BD\galaxy`
- FTS5-поиск по анализам
