# TaskPlan — сервис планирования и управления задачами

> **Версия:** 1.0 от 07.08.2026
> **Родительский том:** [Главный том документации](../master-index.md)

---

## 1. Назначение

TaskPlan — сервис управления объёмными задачами через WPF-интерфейс, трекер этапов и диспетчер задач. Позволяет разбивать большие задачи на этапы, отслеживать прогресс и переключаться между задачами.

**Файлы:**
- `scripts\Show-TaskPlanGUI.ps1` — WPF ДО
- `scripts\TaskPlan-Tracker.ps1` — ядро логики этапов
- `scripts\TaskPlan-Manager.ps1` — диспетчер множества задач
- `scripts\TaskPlan-Tests.ps1` — 15 автотестов

---

## 2. Вкладки ДО

| Вкладка | Назначение |
|---------|-----------|
| **Список задач** | Таблица этапов с цветовой маркировкой (зелёный=[x], жёлтый=[~], красный=[!], серый=[ ]) |
| **Управление** | Создание/редактирование планов, установка статусов, добавление этапов |
| **Тесты** | Запуск 15 автотестов полного цикла |

---

## 3. Статусы этапов

| Маркер | Статус | Значение |
|--------|--------|----------|
| `[ ]` | todo | Не начат |
| `[~]` | wip | В работе |
| `[x]` | done | Готово |
| `[!]` | defer | Отложен на дорогую LLM |

---

## 4. Диспетчер задач

- Хранит `task_index.json` в корне задач
- Поддерживает: create, list, show, switch, suspend, resume, edit-prompt, delete
- **Текущая задача** — одна активная, остальные paused при переключении

---

## 5. OUTPL — анализ ошибок TaskPlan

`scripts\Out-TaskPlan.ps1` анализирует `temp\taskplan_last_output.log`, распознаёт 8 типов ошибок и выдаёт диагностику с автоисправлением.

---

## 6. Экономическая выгода

- **Структурирование больших задач:** разбивка на этапы с отслеживанием
- **Передача контекста:** любая LLM продолжает с контрольной точки
- **Автотестирование:** 15 тестов без участия человека
