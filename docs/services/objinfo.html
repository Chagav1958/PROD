ObjectInfo — справочник объектов PB и SQL


> Версия: 1.0 от 07.08.2026

> Родительский том: Главный том документации


---


1. Назначение


ObjectInfo — WPF-приложение для просмотра справочной информации по объектам PowerBuilder и SQL: структура, зависимости, анализы, свойства.


Файлы:

- scripts\Show-ObjectInfo-GUI.ps1 — основное окно

- scripts\Show-ObjectInfo.cs — C# backend (парсинг, поиск, кодировки)

- bin\Show-ObjectInfo.bat — лаунчер


---


2. Возможности


ФункцияОписание
Поиск объектовПо имени, типу, библиотеке
Просмотр структурыПараметры процедур, колонки DataWindow, свойства
Граф зависимостейКто вызывает объект / кого вызывает объект (глубина 1-3)
Сравнение Main/CurrentMD5-хеши, размеры, даты модификации
АнализыПоиск по тексту сохранённых анализов (FTS5)
КодировкаАвтоопределение UTF-8/CP1251/UTF-16 по BOM
