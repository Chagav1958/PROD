# ПРОДОБР — сервис обработки задач с прогресс-барами

> **Версия:** 1.0 от 07.08.2026
> **Родительский том:** [Главный том документации](../master-index.md)

---

## 1. Назначение

ПРОДОБР (ПРОДолжение ОБРаботки) — WPF-окно для продолжения работы по утверждённому плану. Находит задачу в `pending-tasks.md` или `tasks/` со статусом [~] или [ ] и продолжает выполнение с последней незавершённой контрольной точки.

**Файлы:**
- `scripts\Show-ProdObr-GUI.ps1` — WPF-окно
- `scripts\AutoTest-ProdObr.ps1` — автотест
- `bin\Show-ProdObr.bat` — лаунчер

---

## 2. Возможности

| Функция | Описание |
|---------|----------|
| **Автопоиск задачи** | По `pending-tasks.md` или папке `tasks/` |
| **Прогресс-бары** | Фаза (контрольная точка) + шаг (текущий объект) |
| **Кнопка «След. этап»** | Переход к следующей КТ после завершения |
| **Автопереход** | Чек-бокс для автоматического перехода |
| **Headless-режим** | `-Headless` для CI/автоматизации |

---

## 3. Интеграция с TaskPlan

ПРОДОБР читает `ПЛАН_РЕАЛИЗАЦИИ.txt` и `plan_state.json` из папки задачи, отображает статус этапов и позволяет продолжить с любого места.

---

## 4. Экономическая выгода

- **Непрерывность:** любая LLM-сессия продолжает с контрольной точки
- **Визуализация:** прогресс-бары показывают движение по этапам
- **Автоматизация:** `-Headless` для ночных прогонов
