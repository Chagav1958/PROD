Плагины OpenCode — каталог и описание


> Версия: 1.0 от 07.08.2026

> Родительский том: Главный том документации


---


1. Общее описание


Плагины OpenCode — JavaScript/Node.js модули, расширяющие функциональность OpenCode Desktop. Загружаются при старте и регистрируют хуки на события чата, сессии и файловой системы.


Конфигурация: opencode.jsonc → секция plugin.


---


2. Плагины проекта


2.1. save-prompts.js

Файл: .opencode\plugins\save-prompts.js


Автосохранение промптов пользователя в temp\user_prompts.log. Каждый промпт длиной > 20 символов записывается с датой и временем.


2.2. russian-compaction.js

Файл: .opencode\plugins\russian-compaction.js


Заменяет стандартный английский промпт сжатия сессии на русский. Сводки диалогов создаются на русском языке (Objective → Цель, Work State → Состояние работы и т.д.).


2.3. claude-code.js

Файл: .opencode\plugins\claude-code.js


Интеграция с Claude Code для анализа и рефакторинга объектов PowerBuilder (.sr*) и SQL (.sql). Предоставляет инструменты claude_pb и claude_sql.


2.4. loop-guard.js

Файл: .opencode\plugin\loop-guard.js


Защита от бесконечных циклов правок. Отслеживает количество последовательных правок одного файла и блокирует при превышении порога.


2.5. task-progress.js

Файл: .opencode\plugin\task-progress.js


Отслеживание прогресса задач. Интегрируется с todowrite для визуализации состояния этапов.


2.6. @betterspec/opencode

Тип: npm-пакет


Улучшенная спецификация промптов. Добавляет валидацию и форматирование инструкций.


2.7. @relf108/opencode-watchdog

Тип: npm-пакет


Система безопасности правок:

- Scope enforcement — блокировка правок вне утверждённого scope.txt

- Baseline testing — тесты до/после изменений

- Commit gate — блокировка git commit без test-baseline.txt и test-latest.txt


---


3. Экономическая выгода


- Автосохранение промптов: восстановление контекста после сбоя

- Русские сводки: экономия токенов на переводе

- Watchdog: предотвращение случайных правок вне scope
