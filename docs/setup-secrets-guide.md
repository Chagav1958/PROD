# Setup-Secrets — сервис управления секретными данными

Дата: 05.08.2026

## Назначение

Сервис `Setup-Secrets` предназначен для безопасного ввода, шифрования и хранения секретных данных проекта (пароли, токены, ключи API) при развёртывании проекта AIS на других компьютерах, а также для замены устаревших секретов на новые.

## Запуск

```
bin\Setup-Secrets.exe
```

Или с автотестом:

```
bin\Setup-Secrets.exe --autotest commands.txt
```

## Интерфейс

Диалоговое окно в стиле СТАНДАРТ2 с пятью вкладками:

| Вкладка | Поля |
|---------|------|
| **Sybase** | Пароль подключения к БД |
| **VSS** | Логин, пароль, мастер-ключ Visual SourceSafe |
| **Jira** | API-токен, токен доступа |
| **OpenCode API** | Пароль локального API |
| **EWS (Exchange)** | Сервер URL, email, логин (DOMAIN\\user), пароль |

## Шифрование

Все секретные поля шифруются через **Windows DPAPI** (`ProtectedData.Protect`) с привязкой к учётной записи текущего пользователя. Это означает:

- Секреты может расшифровать **только тот же пользователь на том же компьютере**
- При переносе на другой компьютер старые зашифрованные значения не читаются — поля остаются пустыми
- После ввода новых значений они сохраняются зашифрованными для текущего пользователя

## Хранилища

| Файл | Содержимое | Защита |
|------|-----------|--------|
| `config\.local_secrets.json` | Sybase, VSS, Jira, OpenCode API (зашифровано) | `.gitignore`, DPAPI |
| `~\.config\ews-mcp\credentials.env` | EWS (Exchange): сервер, email, логин, пароль | вне репозитория |

## Развёртывание на другом компьютере

1. Скопировать проект (без папок `.venv`, `node_modules`)
2. Скопировать `config\.local_secrets.example.json` → `config\.local_secrets.json`
3. Запустить `bin\Setup-Secrets.exe`
4. Заполнить все вкладки своими данными
5. Нажать «Сохранить»

## Замена секретов

1. Запустить `bin\Setup-Secrets.exe`
2. Внести новые значения в поля
3. Нажать «Сохранить» — старые значения перезаписываются

## Журналирование

Все действия записываются в `tech_journal_*.log` (рядом с EXE):
- `[START]` — запуск
- `[INFO] Loaded` — загрузка секретов
- `[INFO] Saved` — сохранение
- `[WARN]` — поля, которые не удалось расшифровать
- `[ERROR]` — ошибки

## Автотестирование

Формат команд (`commands.txt`):

```
set sybase mypass
set jira_token sk-abc123
save
wait 500
close
```

Команды: `set <поле> <значение>`, `save`, `close`, `wait <мс>`, `log <текст>`.

## Технология

- C# (.NET 6), WPF
- `System.Security.Cryptography.ProtectedData` (DPAPI)
- Стиль: СТАНДАРТ2 (скруглённые углы, кастомный заголовок, прозрачность)
