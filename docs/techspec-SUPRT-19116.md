### 2.2 Данные

- `com_id = 186262303` (os_policy_id = 139477263)

### 2.3 Логика

**Результаты диагностики (PROD, galaxy/golden, 10.09.2026):**

```sql
-- Комиссии (ais_commission):
-- com_id=186262303: entity_id=67339, ag_id=NULL, com_type=B, system=AVT, state=A, os_policy_id=139477263
-- com_id=187671845: entity_id=67339, ag_id=NULL, com_type=B, system=AVT, state=A, os_policy_id=140633041

-- Посредник (ais_entity_data):
-- entity_id=67339, subj_id=4912608, entity_legal_code='C', entity_type_id=2

-- Договор (ais_entity_basis):
-- mis_ag_id=65461349, ag_id=484460, entity_id=67339, state=1 -- договор существует и активен

-- Полисы (oss_agreement):
-- os_policy_id=139477263: blocked=NULL (не заблокирован)
-- os_policy_id=140633041: (данные не выведены, но комиссия существует)

-- Посредники по полисам (oss_middleman):
-- os_policy_id=139477263: mid_name_id=7375864, business_role='Курьер', cover_id=0
-- os_policy_id=140633041: записей НЕТ
```

**Вывод:** Обнаружены **две проблемы**:

1. **`ag_id=NULL`** в таблице `ais_commission` для комиссий 186262303 и 187671845, хотя у посредника entity_id=67339 есть активный договор ag_id=484460. Это вызывает ошибку «В комиссии нет АД» (RC=-105).

2. **В таблице `oss_middleman` отсутствует посредник с ролью Брокер** для обоих полисов:
   - Для полиса 139477263 есть только посредник с ролью «Курьер» (mid_name_id=7375864)
   - Для полиса 140633041 записей в `oss_middleman` нет вообще
   
   Это вызывает ошибку «В полисе нет посредника... с ролью Брокер».

**Проверка АД в окне комиссий** (`w_middleman_commission_b2b.srw`, строки 491-500):

```powerscript
// Для комиссий Агентов (com_type = 'A') нельзя менять статус на Принято или Удержано,
// если в комиссии нет АД (ag_id <= 0) и птичка "Без проверки аг. договора" не установлена.
if row > 0 and (as_status = 'A' or as_status = 'D') and ls_com_type = "A" then
    ld_ag_id = dw_list.GetItemDecimal(row, "ag_id")
    if nvl(ld_ag_id, 0) <= 0 and cbx_ignore.checked = FALSE then li_res = -1
    if li_res = -1 then
        MessageBox("Внимание", "Для комиссий Агентов нельзя менять статус на Принято или Удержано~r~nесли в комиссии нет АД и птичка 'Без проверки аг. договора' не установлена.")
        return -1
    end if
end if
```

**Процедура выборки комиссий** (`usp_middleman_commission.sql`, строка 176):
- Возвращает поле `c.ag_id` из таблицы `ais_commission`
- Связь с договорами: `LEFT OUTER JOIN ais_entity_basis agr ON (agr.mis_ag_id = c.ag_id)` (строка 210)

**Гипотеза причины ошибки:**
1. Для комиссий `com_id = 187671845, 186262303` поле `ag_id` в таблице `ais_commission` не заполнено (NULL или 0).
2. При формировании акта вызывается проверка наличия АД в комиссии → ошибка «В комиссии нет АД» (RC = -105).
3. Также проверяется наличие посредника в полисе (таблица `oss_middleman` или аналог) → ошибка «В полисе нет посредника... с ролью Брокер».
4. В ОСС посредник и договор существуют, но в AIS данные не синхронизированы или не были автоматически подставлены при создании комиссии.
