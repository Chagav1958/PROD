Причина срабатываний (подтверждено 17.07.2026):

  • PDM:Trojan.Win32.Generic на OpenCode.exe — поведенческий анализ (HIPS).

Приложение легитимно запускает powershell, пишет файлы проекта, обращается

к LLM API. SHA256 OpenCode.exe = 673025C27F2FDDD129D22DFAC9F5755BA3455C7F2C3830D12F11F91BD49E3BCA

(совпадает с хэшем из отчёта АВ — файл не изменён, это false positive).

  • HEUR:Trojan.PowerShell.Obfus.b на файл кэша f_0001ac в Cache_Data —

бинарный кэш Electron, содержит фрагменты веб-контента. Удалён АВ,

восстановления не требует (пересоздаётся автоматически).
