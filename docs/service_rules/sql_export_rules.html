Правила сервиса SQL-экспорт


Состав сервиса


ФайлНазначение
bin\SQL_exp_param.batПолный SQL-экспорт (все DDL-объекты) с сервера Sybase ASE
bin\SQL_exp_ready.batЭкспорт выборочных объектов из папки Ready
bin\SQL_exp_single.batЭкспорт одного объекта по типу и имени

Зависимости


- isql (Sybase ASE) — должна быть в PATH (утилита проверяется через where isql)

- Учётная запись vchaga (жестко закодирована)

- Пароль Sybase — передаётся только через параметры, никогда не хранится в файлах


Известные ошибки и их предотвращение


Общие для всех BAT-скриптов


1. Путь %~dp0 оканчивается на \

- %SCRIPT_DIR% получает значение %~dp0 и затем обрезает последний символ (%SCRIPT_DIR:~0,-1%)

- Если скрипт в корне диска (редко), обрезание удалит не \, а букву диска

- Проверка: убедиться, что %SCRIPT_DIR% — валидный путь без \ в конце


2. chcp 1251

- Все BAT-файлы переключают консоль на Windows-1251 (chcp 1251 >nul)

- Должно быть первой командой после @echo off


3. Проверка isql

- where isql >nul 2>nul — если isql не найден, скрипт завершается

- Важно: утилита не входит в состав проекта, должна быть установлена отдельно (Sybase ASE Client)


4. Экранирование ^ в bat-файлах

- Символ ^ используется для экранирования |, >, & внутри echo в BAT

- Пример: select name from sysobjects where type='P' and user_name(uid)='dbo' order by name — в оригинале echo select rtrim(name^) from sysobjects where type='P' and user_name(uid^)='dbo' order by name >> get_procs.sql

- Правило: любой SQL-запрос внутри echo должен экранировать ( ) > | через ^


SQL_exp_param.bat


5. *Путь к gen_.sql файлам**

- Скрипт использует %SCRIPT_DIR%\gen_tables.sql, gen_indexes.sql, gen_pk.sql, gen_fk.sql, gen_grants.sql

- Эти файлы ожидаются рядом с BAT-файлом

- Ошибка: если файлы отсутствуют, isql упадёт с ошибкой "Input file not found"

- Проверка: убедиться, что файлы существуют в bin/


6. Путь вывода BASEDIR

- %BASEDIR% = %SCRIPT_DIR%\BD\%SERVER%\%DATABASE%

- %SCRIPT_DIR% — это bin/, значит экспорт идёт в bin/BD/...

- Это может быть неочевидно, если смотреть только на config.json


7. Поддиректории создаются принудительно

- mkdir "%BASEDIR%\Procedure" 2>nul — ошибки подавлены

- Если диск недоступен — ошибка не отобразится, скрипт продолжит работу


8. Очистка временных файлов

- del "%BASEDIR%\LOGS\_tp.sql" ... 2>nul — ошибки подавлены

- После удаления скрипт не проверяет, что все временные файлы удалены


9. Завершение с pause

- Скрипт всегда вызывает pause в конце, даже при успехе

- В GUI-режиме это нежелательно (ожидание нажатия клавиши)

- Выход: параметр -NoPause или перенаправление ввода в GUI


SQL_exp_ready.bat


10. Структура папок Ready

- Ожидается структура: ReadyMerged\Server\Database\Type\ObjectName.sql

- Если структура нарушена — REL разбирается неправильно (delims=\ для tokens=1,2,3)

- Правило: при изменении структуры папок Ready нужно обновить парсинг REL


11. Пароль с восклицательным знаком !

- setlocal enabledelayedexpansion — ! в пароле будет интерпретироваться как начало выражения

- Правило: если пароль содержит !, нужно экранировать ^^! или отключить delayed expansion на время ввода пароля


12. Перезапись исходных файлов

- Скрипт сохраняет результат прямо в файлы Ready-папки (-o "%~1")

- Это изменяет оригинальные файлы из Ready

- Важно: перед запуском убедиться, что есть резервная копия ReadyMerged


13. TOTAL_OK / TOTAL_FAIL передаются через endlocal

- endlocal & set TOTAL_OK=%TOTAL_OK% & set TOTAL_FAIL=%TOTAL_FAIL%

- Это хрупкая конструкция — если добавить больше переменных, нужно обновлять все endlocal


SQL_exp_single.bat


14. OBJ_TYPE нечувствителен к регистру

- Используется /i в if: if /i "%OBJ_TYPE%"=="Procedure"

- Допустимые типы: Procedure, Function, Trigger, Table, Index, PK, FK, Grant


15. Все типы используют одинаковый SQL-запрос

- Для Procedure, Function, Trigger, Table используется один и тот же запрос select text from syscomments where id=object_id(...)

- Для Tables, Indexes, PK, FK, Grants запрос не подходит — они экспортируются только через gen_*.sql в SQL_exp_param.bat

- Ограничение: SQL_exp_single.bat не может выгрузить структуру таблицы, индекса или гранта по одному объекту


Рекомендации


- При запуске через GUI пароль экранируется: $escapedPassword = $password -replace "'", "''"

- Таймаут вывода GUI настраивается через gui.output_timeout_seconds в config.json

- Если скрипт выполняется дольше таймаута — процесс будет прерван
