# Правила сервиса Тестирование (test_sql_export)

## Состав сервиса

| Файл | Назначение |
|------|------------|
| `scripts\test_sql_export.ps1` | Автоматизированная проверка целостности SQL-экспорта и кодировки |

## Зависимости

- **isql** (Sybase ASE) — для выполнения экспорта
- Тестовые файлы: `check_agent.sql` и `usp_add_entity_data.sql`

## Известные ошибки и их предотвращение

1. **Жёстко закодированные пути**
   - `$readyDir = "C:\Temp\TestReady_SQL"` — конкретная временная папка
   - `$origDir = "C:\AIS\AI\Prod\BD"` — конкретная папка с оригиналами
   - **Правило:** при переносе проекта обновить эти пути

2. **Только два тестовых файла**
   - `check_agent.sql` — проверка бинарного соответствия
   - `usp_add_entity_data.sql` — проверка русской кодировки (Windows-1251)
   - **Правило:** при добавлении новых тестов расширять массив `$testFiles`

3. **Кодировка Windows-1251**
   - Проверка: поиск байтов CP1251 кириллицы (0xC0-0xFF, 0xA8, 0xB8)
   - Проверка на UTF-16 BOM (0xFF 0xFE) и UTF-8 BOM (0xEF 0xBB 0xBF)
   - Проверка на mojibake: `?` после не-ASCII байтов
   - **Правило:** SQL-файлы должны быть в Windows-1251, без BOM

4. **Проверка isql сообщений**
   - `Select-String -Pattern "^(Msg |Server '|\(return status)"`
   - Если в файле есть строки isql ошибок — тест падает
   - **Важно:** isql иногда пишет "(return status 0)" в конце файла — это триггерит проверку

5. **Проверка CREATE заголовка**
   - `Select-String -Pattern "^\s*create\s+(proc|procedure|function|trigger)\s+"`
   - Если файл не содержит CREATE — тест падает
   - Подходит для процедур, функций, триггеров; не подходит для DDL (таблицы, индексы)

6. **Завершение с exit code**
   - `exit ([int](-not $allPassed))`
   - 0 = все тесты пройдены, 1 = есть ошибки
   - **Правило:** проверять `$LASTEXITCODE` после запуска

## Рекомендации

- Для запуска из GUI: указать пароль Sybase и TaskName
- Для ручного запуска: `.\test_sql_export.ps1 -Password <pwd> -TaskName TEST`
- Скрипт можно расширить для проверки всех файлов в BD/ папке
- Кодировка консоли: `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`
