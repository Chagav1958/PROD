# Правила сервиса Сравнение и проверка (Compare)

## Состав сервиса

| Файл | Назначение |
|------|------------|
| `scripts\Compare-Export.ps1` | Сравнение готовности объектов к выпуску (Ready → Current → Main) |
| `scripts\Compare-PB.ps1` | Сравнение PB-объектов (PB_Current и PB_Main по MD5) |
| `scripts\Compare-SQL.ps1` | Сравнение SQL-экспорта (dev_golden и galaxy по MD5) |

## Зависимости

- **PowerShell 5.1** — все скрипты используют PS 5.1-совместимый синтаксис
- **TortoiseMerge** (опционально) — для визуального сравнения файлов (Compare-Export с флагом `-ShowDiff`)
- **Create-RFC.ps1** — вызывается из Compare-Export при `-CreateRFC`

## Известные ошибки и их предотвращение

### Compare-Export.ps1

1. **Синтаксические ошибки парсера PS 5.1 с `|`** (Bug-026)
   - PowerShell 5.1 некорректно парсит строки с символами `|` и `/` внутри кавычек в «сложных» контекстах
   - **Симптом:** неожиданные синтаксические ошибки "Unexpected token '|'"
   - **Исправление:** строки для JIRA-таблицы собираются в переменные перед `AppendLine()`:
     ```powershell
     $jiraHdr = "Project/Server|Library/DB|Object Name|Info|"
     [void]$sb.AppendLine($jiraHdr)
     ```
   - **Правило:** избегать прямого вызова `.AppendLine("...|...|...")` — сначала присвоить в переменную

2. **Array literal с `/base`** (Bug-026)
   - `$diffArgs = @("/base", ...)` — замените одинарные кавычки на двойные в настройках, так как PS 5.1 может падать на `@('/base', ...)`
   - **Правило:** использовать `@('/base', ...)` с одинарными кавычками

3. **Путь к config.json** (Bug-026)
   - По умолчанию `$ConfigPath = "C:\AIS\AI\Prod\config\config.json"` (исправлено с C:\AIS\AI\Prod\config.json)
   - **Правило:** путь к config.json указывать через `config\config.json` (относительно корня)

4. **Поиск TaskFolder при запуске без параметров**
   - Если не передан `$TaskFolder` или `-TaskName`, скрипт ищет последнюю изменённую папку `SYBASE-*` в `release_root`
   - **Правило:** если папка не найдена — скрипт завершается с `throw`

5. **ReadyMerged — слияние нескольких Ready_* папок**
   - Все папки `Ready_*` (кроме `Ready_`) сортируются по `LastWriteTime`
   - Файлы копируются с перезаписью: более свежий файл заменяет старый
   - **Правило:** `Ready_` (с пустой датой) исключается из обработки

6. **Статусы проверки**
   - `NOT_IN_CURRENT`: объект отсутствует в Current → ошибка
   - `DIFF_CURRENT`: отличается от Current → ошибка
   - `NEW_OBJECT`: новый объект (нет в Main) → предупреждение
   - `SAME_AS_MAIN`: совпадает с Main (не изменился) → ошибка
   - `OK`: Ready = изменён относительно Main и совпадает с Current → готов

7. **RFC создаётся ТОЛЬКО если все объекты READY**
   - Если есть `NOT_READY` — RFC не создаётся (даже при `-CreateRFC`)
   - **Правило:** не обходить это ограничение без явного запроса

### Compare-PB.ps1

8. **Default config path**
   - По умолчанию `C:\AIS\AI\Prod\config.json` (БЕЗ `config\`) — это legacy
   - При переносе на другую машину путь может не совпадать
   - **Правило:** использовать `Join-Path $PSScriptRoot "..\config\config.json"` или параметр

9. **Хеши MD5**
   - Сравнение идёт по полному содержимому файла (Get-FileHash -Algorithm MD5)
   - **Важно:** файлы должны быть в кодировке Windows-1251 (как при экспорте isql)

### Compare-SQL.ps1

10. **Структура папок BD**
    - Ожидается: `BD\dev_golden\<database>\Procedure\`, `BD\dev_golden\<database>\Functions\`, `BD\dev_golden\<database>\Triggers\`
    - Аналогично для `BD\galaxy\`
    - **Ошибка:** если папка `Functions` (с большой буквы) не совпадает с реальной — файлы не найдутся

11. **Общие базы данных**
    - Сравниваются только базы, присутствующие на обоих серверах
    - База `golden` — основная, но могут быть и другие (mis, etc.)

## Рекомендации

- Все три скрипта сохраняют отчёт в текстовый файл (кодировка Default = Windows-1251)
- Compare-Export дополнительно создаёт JIRA-таблицу в отчёте
- Compare-PB и Compare-SQL показывают результаты по библиотекам/базам
- Для быстрой проверки без GUI: запустить PowerShell и выполнить скрипт с параметрами
