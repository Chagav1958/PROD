Инструкция переноса OpenCode на другой ПК

1. Установка OpenCode

Windows (рекомендуется WSL, но можно и natively)


# Через npm (нужен Node.js 18+)
npm install -g opencode-ai

# Или через Scoop
scoop install opencode

# Или через Chocolatey
choco install opencode

Проверка установки


opencode --version

2. Бесплатные LLM провайдеры (OpenCode Zen)

OpenCode Zen предоставляет бесплатные модели (rotating, time-limited):

МодельModel IDКонтекстОписание
DeepSeek V4 Flash`zen/deepseek-v4-flash-free`1MБыстрая, большая
MiMo V2.5`zen/mimo-v2.5-free`1MБыстрая
Nemotron 3 Ultra`zen/nemotron-3-ultra-free`1MМощная
Hy3 Preview`zen/hy3-preview-free`256KPreview
North Mini Code`zen/north-mini-code-free`256KКодинг
Big Pickle`zen/big-pickle`N/AStealth

Настройка OpenCode Zen

  1. Зарегистрируйтесь на https://opencode.ai/auth
  2. Добавьте биллинг (для бесплатных моделей ключ всё равно нужен)
  3. Скопируйте API key
  4. В OpenCode TUI: u{FFFD}/connectu{FFFD} → выберите "OpenCode Zen" → вставьте ключ
  5. u{FFFD}/modelsu{FFFD} — увидите список доступных моделей

Конфигурация в opencode.jsonc


{
  "$schema": "https://opencode.ai/config.json",
  "model": "zen/deepseek-v4-flash-free",
  "small_model": "zen/mimo-v2.5-free",
  "provider": {
    "opencode": {
      "name": "OpenCode Zen (бесплатные)",
      "whitelist": [
        "deepseek-v4-flash-free",
        "mimo-v2.5-free",
        "nemotron-3-ultra-free",
        "hy3-preview-free",
        "north-mini-code-free",
        "big-pickle"
      ]
    }
  }
}
u{FFFB}Примечание:u{FFFB} Бесплатные модели ротируются — иногда могут быть недоступны.
Для стабильной работы используйте u{FFFD}opencode-gou{FFFD} ($10/мес) или u{FFFD}routeraiu{FFFD}.

4. Конфигурация opencode.jsonc

Проектная конфигурация (u{FFFD}C:\AIS\AI\Prod\opencode.jsoncu{FFFD})

Копируйте весь файл. Он содержит:

  • Провайдеры (routerai, anthropic, openai, deepseek, yandex)
  • MCP серверы (atlassian, sybase-docs, rules-mcp, knowledge)
  • Плагины

Пользовательская конфигурация (u{FFFD}~/.config/opencode/opencode.jsoncu{FFFD})

Содержит:

  • Ollama (локальные модели)
  • Базовые настройки

ВАЖНО: Формат MCP в opencode.jsonc

OpenCode использует ключ u{FFFD}mcpu{FFFD}, а u{FFFB}НЕu{FFFB} u{FFFD}mcpServersu{FFFD} (это формат Claude Desktop).

u{FFFB}Правильно:u{FFFB}


{
  "mcp": {
    "rules-mcp": { ... },
    "knowledge": { ... }
  }
}

u{FFFB}НЕПРАВИЛЬНО (вызовет ConfigInvalidError):u{FFFB}


{
  "mcpServers": {
    "rules-mcp": { ... }
  }
}

Если при запуске ошибка u{FFFD}Unrecognized key: mcpServersu{FFFD} — замените u{FFFD}mcpServersu{FFFD} на u{FFFD}mcpu{FFFD}.

5. Пошаговый перенос

На старом ПК

  1. Убедитесь, что все MCP серверы остановлены
  2. Скопируйте всю папку u{FFFD}C:\AIS\AI\Prod\u{FFFD} (или её ключевые части)
  3. Скопируйте u{FFFD}C:\AIS\AI\rules-mcp\u{FFFD}
  4. Скопируйте u{FFFD}C:\Users\vchaga\.config\opencode\u{FFFD}
  5. Экспортируйте API ключи (или запомните их)

На новом ПК

  1. Установите Python 3.12+ и Node.js 18+
  2. Установите OpenCode: u{FFFD}npm install -g opencode-aiu{FFFD}
  3. Скопируйте проект в u{FFFD}C:\AIS\AI\Prod\u{FFFD}
  4. Создайте venv для MCP серверов:
    5. 
   # rules-mcp
   cd C:\AIS\AI\rules-mcp
   python -m venv venv
   venv\Scripts\activate
   pip install fastmcp>=3.0.0

   # knowledge
   cd C:\AIS\AI\Prod\scripts\knowledge_mcp
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt

   # sybase-docs-mcp (если нужен)
   cd C:\AIS\AI\sybase-docs-mcp
   python -m venv venv
   venv\Scripts\activate
   pip install -e .
  5. Настройте провайдеры: u{FFFD}/connectu{FFFD} → OpenCode Zen → вставьте ключ
  6. Проверьте: u{FFFD}/modelsu{FFFD} — увидите бесплатные модели
  7. Запустите OpenCode в папке проекта: u{FFFD}cd C:\AIS\AI\Prod && opencodeu{FFFD}

6. Альтернатива: Ollama (полностью локально, бесплатно)

Если не хотите использовать облачные API:


# Установите Ollama: https://ollama.com
ollama pull qwen2.5-coder:32b
ollama pull qwen2.5-coder:14b
ollama pull deepseek-coder-v2:16b

Конфигурация в u{FFFD}~/.config/opencode/opencode.jsoncu{FFFD}:


{
  "model": "ollama/qwen2.5-coder:32b",
  "small_model": "ollama/qwen2.5-coder:7b",
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama (local)",
      "options": {
        "baseURL": "http://localhost:11434/v1"
      },
      "models": {
        "qwen2.5-coder:32b": {
          "name": "Qwen 2.5 Coder 32B (local)",
          "limit": { "context": 32768, "output": 8192 }
        }
      }
    }
  }
}
u{FFFB}Требуется:u{FFFB} GPU с 16+ GB VRAM для 32B моделей.

7. Проверка работы

  1. Запустите OpenCode: u{FFFD}opencodeu{FFFD}
  2. Проверьте MCP: в чате спросите "покажи сокращение ДО"
  3. Проверьте知识: "найди в базе знаний исправление бага"
  4. Проверьте модель: u{FFFD}/modelsu{FFFD} — выберите бесплатную модель
  5. Протестируйте: "создай простой SQL запрос"
