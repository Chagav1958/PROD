## 1. КОНТЕКСТ

### 1.1 Проблема/запрос
Доработки справочника брокеров для перевода партнёров на автоматизированную выгрузку КВ. Расширение кодов `generation_point` (СР12, СР13, СР14, СР123, СР124, СР134), добавление признака «Дата акта», кнопки «Обновить» и dblclick → карточка посредника.

- Затронутые продукты: AIS

### 2.3 Логика

**Определение недели (usp_broker_commission_ex, строки 1908-1913):**
```sql
SELECT @numWeek = Convert(int, datename(dd, @DateCurrent)) / 7 + 
    Case When Convert(int, datename(dd, @DateCurrent)) % 7 = 0 then 0 else 1 end

AND p.generation_point LIKE '%' + Convert(varchar(1), @numWeek) + '%'
```

**Правило:** код содержит цифру N → попадает в среду N. СР0 — все среды.

### 3.3 Блок 3: Дата акта

**Цель:** Добавить признак «Дата акта» + отбор комиссий по дате оплаты.

**Изменения:**

| Объект | Библиотека | Изменение |
|--------|------------|-----------|
| `ais_cat_pdf_location` | БД | ALTER TABLE — добавить `act_date_mode` |
| `d_ref_pdf_location_card_9039` | golden_sprw | Добавить DDDW/dropdown для `act_date_mode` |
| `d_ais_cat_pdf_location_import` | golden_sprw | Маппинг Excel → `act_date_mode` |
| `usp_broker_commission_ex` | golden | Добавить фильтр по оплате при `act_date_mode='1'` |
| Автогенерация | golden | То же правило |
| Отчёт | golden | Присвоение даты акта — `external_date` |

**DDL:**
```sql
ALTER TABLE ais_cat_pdf_location 
ADD act_date_mode char(1) null
GO

sp_addextendedproperty 'MS_Description', 
    'Режим даты акта: NULL=не указано (default), 1=последний день пред. месяца',
    'user', 'dbo', 'table', 'ais_cat_pdf_location', 'column', 'act_date_mode'
GO
```

**Маппинг:**

| UI | БД | Excel |
|----|----|-------|
| не указано | NULL | пусто и любое значение ≠ `1` |
| последний день пред. месяца | `1` | `1` |

**Вычисление даты акта:**
```sql
DECLARE @act_date datetime
IF @act_date_mode = '1'
    SET @act_date = dateadd(day, -1, dateadd(month, datediff(month, 0, @gen_date), 0))
ELSE
    SET @act_date = @gen_date
```

**Отбор комиссий:**
```sql
AND (p.pay_date IS NOT NULL AND p.pay_date <= @act_date)
```

**Риск:** Средний — затрагивает usp и автогенерацию.

**Цель:** Открытие карточки посредника по dblclick на строке справочника.

**Изменения:**

| Объект | Библиотека | Изменение |
|--------|------------|-----------|
| `d_ref_pdf_location_card_9039` | golden_sprw | Добавить обработчик dblclick |

**Реализация (псевдокод PB):**
```powershell
// ue_dblclick в окне справочника
Long ll_entity_id
ll_entity_id = dw_list.GetItemNumber(row, "entity_id")

if IsNull(ll_entity_id) or ll_entity_id = 0 then
    return  // no-op
end if

// После close — Retrieve
dw_list.Retrieve()
```

**Поведение:**

| Условие | Поведение |
|---------|-----------|
| `entity_id` пустой | no-op |
| посредник не найден | карточка не открывается |
| найден | стандартная карточка |

**Риск:** Низкий — стандартный PB-паттерн.
