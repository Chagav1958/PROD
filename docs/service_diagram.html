2. Потоки данных между каталогами

Тип диаграммы: ER-диаграмма (Entity-Relationship)

Три типа источников: рабочие копии PB (Current/Main), БД Sybase (dev_golden/galaxy), VSS. Результаты экспорта сравниваются с объектами из папок Ready.

erDiagram WORK_GOLD ||--o{ PB_CURRENT : "PblDump экспорт" SRC125 ||--o{ PB_MAIN : "PblDump экспорт" DEV_GOLDEN||--o{ BD_CURRENT: "isql экспорт" GALAXY ||--o{ BD_MAIN : "isql экспорт" VSS ||--o| WORK_GOLD : "Get Latest" VSS ||--o| SRC125 : "Get Latest" READY_FOLDER ||--o{ READY_MERGED : "merge по дате" RELEASE_ROOT ||--o{ READY_FOLDER : "содержит" PB_CURRENT ||--o{ READY_MERGED : "MD5 сравнение" PB_MAIN ||--o{ READY_MERGED : "MD5 сравнение" BD_CURRENT ||--o{ READY_MERGED : "MD5 сравнение" BD_MAIN ||--o{ READY_MERGED : "MD5 сравнение" READY_MERGED ||--|| RELEASE_REPORT : "генерация" PB_CURRENT ||--o{ COMPARE_PB_REPORT : "Compare-PB" PB_MAIN ||--o{ COMPARE_PB_REPORT : "Compare-PB" BD_CURRENT ||--o{ COMPARE_SQL_REPORT: "Compare-SQL" BD_MAIN ||--o{ COMPARE_SQL_REPORT: "Compare-SQL" READY_MERGED ||--o{ TORTOISE_MERGE : "визуальное сравнение" WORK_GOLD { string path "C:\Work\gold" string type "PB Current source" } SRC125 { string path "C:\SRC125\gold" string type "PB Main source" } DEV_GOLDEN { string server "dev_golden" string db "golden" } GALAXY { string server "galaxy" string db "golden" } PB_CURRENT { string path "PB_Current/" string ext ".sr*" } PB_MAIN { string path "PB_Main/" string ext ".sr*" } BD_CURRENT { string path "BD/dev_golden/golden/" string ext ".sql" } BD_MAIN { string path "BD/galaxy/golden/" string ext ".sql" } READY_FOLDER { string pattern "Ready_YYYY_MM_DD" string contents ".sr* + .sql" } READY_MERGED { string path "C:\Temp\ReadyMerged" string rule "newest wins" } RELEASE_REPORT { string file "release_report.txt" string enc "Windows-1251" }
Алгоритм merge Ready: папки Ready_YYYY_MM_DD сортируются по убыванию даты. Для каждого объекта (по имени без расширения) берётся первое вхождение — самая свежая версия. Результат копируется в ReadyMerged/<Task>.

8. Compare & Verify: состояния объектов

Тип диаграммы: Диаграмма состояний (State diagram)

Compare-Export.ps1 проверяет каждый объект из Ready по MD5. Возможные переходы между статусами:

stateDiagram-v2 [*] --> Scanning : "Запуск Compare-Export" Scanning : Сканирование Ready_* папок Scanning --> Merging : "Сбор всех файлов" Merging : Merge в ReadyMerged Merging --> Checking : "newest версия каждого объекта" Checking : MD5 проверка Checking --> READY : "Ready==Current AND Ready!=Main" Checking --> NOT_READY : "Ready!=Current" Checking --> SAME_AS_MAIN : "Ready==Main" Checking --> NOT_IN_CURRENT : "нет в Current" Checking --> NEW_OBJECT : "нет в Main" READY : READY (ГОТОВО) NOT_READY : NOT_READY (НЕ ГОТОВО) SAME_AS_MAIN : SAME_AS_MAIN NOT_IN_CURRENT : NOT_IN_CURRENT NEW_OBJECT : NEW_OBJECT (НОВЫЙ) NOT_READY --> Diff : "ShowDiff=true" SAME_AS_MAIN --> Diff : "ShowDiff=true" Diff : TortoiseMerge Diff --> Checking : "повторная проверка" NOT_IN_CURRENT --> AutoUpdate : "автообновление" AutoUpdate : PblDump из PBL AutoUpdate --> Checking : "re-compare" READY --> CreateRfc : "все READY" NEW_OBJECT --> CreateRfc : "все READY" NOT_READY --> [*] : "требует исправления" SAME_AS_MAIN --> [*] : "не нужен в релизе" CreateRfc : Create-RFC.ps1 CreateRfc --> Report : "RFC создан" CreateRfc --> Report : "RFC пропущен" Report : release_report.txt Report --> [*] : "завершено"
Статусы проверки:
  • READY (ГОТОВО) — совпадает с Current, отличается от Main — готов к выводу
  • NOT_READY (НЕ ГОТОВО) — отличается от Current — требуется обновление
  • NEW_OBJECT (НОВЫЙ) — есть в Current, отсутствует в Main — новый объект
  • SAME_AS_MAIN — совпадает с Main — изменений нет
  • NOT_IN_CURRENT — отсутствует в Current — автообновление через PblDump
