1. КОНТЕКСТ


1.1 Проблема/запрос

Доработки справочника брокеров для перевода партнёров на автоматизированную выгрузку КВ. Расширение кодов generation_point (СР12, СР13, СР14, СР123, СР124, СР134), добавление признака «Дата акта», кнопки «Обновить» и dblclick → карточка посредника.

2.3 Логика


Определение недели (usp_broker_commission_ex, строки 1908-1913):

SELECT @numWeek = Convert(int, datename(dd, @DateCurrent)) / 7 +

    Case When Convert(int, datename(dd, @DateCurrent)) % 7 = 0 then 0 else 1 end



AND p.generation_point LIKE '%' + Convert(varchar(1), @numWeek) + '%'

Правило: код содержит цифру N → попадает в среду N. СР0 — все среды.
