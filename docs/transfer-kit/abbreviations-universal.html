Универсальный шаблон сокращений проекта


> Назначение: шаблон файла сокращений для переноса на другой ПК или в другой проект. Адаптируйте таблицы под свой проект, сохраняя структуру разделов.

>

> Кодировка: UTF-8 без BOM.


---


1. Каталоги и наборы исходников


СокращениеПолное имя / ПутьНазначение
Current<путь_к_рабочей_версии>Разрабатываемая версия исходников
Main<путь_к_продакшн_версии>Эталонная (промышленная) версия
Export_Current<папка_экспорта_Current>Экспортированные объекты из Current
Export_Main<папка_экспорта_Main>Экспортированные объекты из Main

> Пример из проекта AIS: Current = C:\Work\gold, Main = C:\SRC125\gold, PB_Current = PB_Current\, BD/dev_golden = BD\dev_golden\.

Адаптация под проект


При переносе в другой проект:


1. Замените пути в разделе 1 на актуальные для нового ПК.

2. Обновите имена серверов и БД в разделе 2.

3. Добавьте специфичные для проекта типы объектов.

4. Дополните список команд своими сокращениями.

5. Убедитесь, что все сокращения используются единообразно в правилах и документации.
