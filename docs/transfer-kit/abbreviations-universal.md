# Универсальный шаблон сокращений проекта

> **Назначение:** шаблон файла сокращений для переноса на другой ПК или в другой проект. Адаптируйте таблицы под свой проект, сохраняя структуру разделов.
>
> **Кодировка:** UTF-8 без BOM.

---

## 1. Каталоги и наборы исходников

| Сокращение | Полное имя / Путь | Назначение |
|------------|-------------------|------------|
| **Current** | `<путь_к_рабочей_версии>` | Разрабатываемая версия исходников |
| **Main** | `<путь_к_продакшн_версии>` | Эталонная (промышленная) версия |
| **Export_Current** | `<папка_экспорта_Current>` | Экспортированные объекты из Current |
| **Export_Main** | `<папка_экспорта_Main>` | Экспортированные объекты из Main |
| **BD_dev** | `<путь_SQL_экспорта_dev>` | SQL-экспорт с сервера разработки |
| **BD_prod** | `<путь_SQL_экспорта_prod>` | SQL-экспорт с промышленного сервера |

> **Пример из проекта AIS:** Current = `C:\Work\gold`, Main = `C:\SRC125\gold`, PB_Current = `PB_Current\`, BD/dev_golden = `BD\dev_golden\`.

---

## 2. Серверы и базы данных

| Имя | Тип | Назначение |
|-----|-----|------------|
| **dev_server** | Сервер СУБД | Разрабатываемая БД |
| **prod_server** | Сервер СУБД | Промышленная БД |
| **db_name** | База данных | Имя БД на обоих серверах |

---

## 3. Типы объектов

| Тип | Расширение | Описание |
|-----|------------|----------|
| **Library** | `.pbl` / `.dll` | Библиотека компонентов |
| **Target** | `.pbt` / `.exe` | Целевой файл сборки |
| **Export** | `.sr*` | Экспортированные объекты |
| **Procedure** | `.sql` | Хранимая процедура |
| **Function** | `.sql` | Функция |
| **Trigger** | `.sql` | Триггер |
| **View** | `.sql` | Представление |

---

## 4. Статусы проверки объектов

| Статус | Значение |
|--------|----------|
| **READY** | Объект готов к выводу в продакшн |
| **NOT_READY** | Объект не готов |
| **NEW_OBJECT** | Новый объект (отсутствует в продакшн) |
| **SAME_AS_PROD** | Совпадает с продакшн |
| **DIFF** | Объекты различаются |

## 6. Команды и промпты

| Сокращение | Значение | Подробнее |
|------------|----------|-----------|
| **TASK** | Начать задачу | Создание структуры папок, плана, выгрузка оригиналов |
| **OUT / ОБР** | Анализ вывода | Чтение лога ошибок и автоисправление |
| **СОКР** | Показать сокращения | Скрипт вывода списка сокращений |
| **ОО** | Продолжить / проверить задачи | Завершить список задач |
| **РР / RR** | Принудительно русский | Переключение языка модели |
| **ДО** | Диалоговое окно | GUI-окно сервиса |
| **ОП** | Операция | Вкладка главного окна, нумерация 1-based |
| **ПБ** | Прогресс-бар | Индикатор выполнения |
| **СТАРТ** | Preflight-проверка | Проверка перед записью файлов |
| **СОХР** | Архив проекта | Создание снапшота |
| **ЗАПОМНИ** | Запомнить правило | Анализ и сохранение правила |
| **FIXSHOW** | Статусы EDIT/FIXED | Показать/изменить статусы операций |
| **GITHUB** | Обновить Git | Add + commit + push |

## 7. Структура папок задачи

| Папка | Назначение |
|-------|-----------|
| `Git_YYYY_MM_DD` | Оригиналы объектов (для сравнения) |
| `Test_YYYY_MM_DD` | Готовые объекты для тестирования |
| `DIAG_YYYY_MM_DD_hh_mm` | Объекты для диагностики |
| `Ready_YYYY_MM_DD` | Готовые объекты (после тестирования) |
| `Read_YYYY_MM_DD` | Объекты, готовые к выводу в продакшн |
| `Describe\` | Описания изменений и анализы |

## Адаптация под проект

При переносе в другой проект:

1. Замените пути в разделе 1 на актуальные для нового ПК.
2. Обновите имена серверов и БД в разделе 2.
3. Добавьте специфичные для проекта типы объектов.
4. Дополните список команд своими сокращениями.
5. Убедитесь, что все сокращения используются единообразно в правилах и документации.
