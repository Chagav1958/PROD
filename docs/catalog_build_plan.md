## Формат записи в ais-catalog

Каждый объект сохраняется через `ais-catalog_save_knowledge`:

```
text: "Имя: usp_agent_policy_list
Тип: Procedure (SQL)
Параметры: @date_begin datetime, @date_end datetime, @ag_id int = null
Связанные таблицы: ag_contract, ag_contract_policy, entity
Назначение: список полисов агента за период
Ключевые слова: агент, полис, период"
tags: "usp_agent_policy_list,Procedure,agent,policy"
```
