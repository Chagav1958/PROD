Конкретный файл для анализа


Основной файл, вызывающий срабатывание — Hide-ConsoleWindow.ps1:


# Скрипт скрытия вспомогательной консоли (19 строк)

$psi = New-Object Diagnostics.ProcessStartInfo

$psi.FileName = "powershell.exe"

$psi.Arguments = "-NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -STA -File ..."

$psi.UseShellExecute = $false

$psi.CreateNoWindow = $true

[Diagnostics.Process]::Start($psi) | Out-Null

Почему срабатывает: Start-Process -WindowStyle Hidden + CreateNoWindow = true — эвристика классифицирует как "скрытый запуск процесса".


Что делает скрипт: скрывает вспомогательную консоль при запуске GUI-приложения. Пользователь видит только графическое окно, консоль работает в фоне.


Файл для передачи в Kaspersky: C:\AIS\AI\Prod\scripts\Hide-ConsoleWindow.ps1


Что я уже сделал для снижения рисков


Ранее в проекте использовался user32.dll P/Invoke (ShowWindow) — он вызывал срабатывания. Я уже заменил его на управляемый .NET-аналог. Текущая реализация максимально безопасна, но эвристика всё равно реагирует на скрытый запуск.
