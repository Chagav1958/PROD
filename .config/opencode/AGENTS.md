# Глобальные правила OpenCode (все проекты)

## СТРОГО: НЕ СОЗДАВАТЬ `.ps1`

- **Создание новых `.ps1`-файлов КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО во всех проектах.**
- **Причина:** антивирус (Kaspersky + Defender) массово удаляет PowerShell-скрипты — потеряны десятки файлов сервисов (Bug-063/064/065).
- **Сервисы и скрипты реализовывать только на:**
  - **C# / .NET** (`dotnet build` / `dotnet publish` → `.exe`) — предпочтительно;
  - **Python** (`.py` / `.pyw`);
  - **.bat / .cmd** — только простой лаунчер, без base64, `IEX`, скрытого запуска и `-ExecutionPolicy Bypass`.
- Существующие `.ps1` не расширять; при доработке логику переносить в C#/Python.
- Любая задача «сделай сервис/скрипт» по умолчанию = C# или Python, а не PowerShell.

## Секреты

- Логины, пароли, токены, API-ключи — НИКОГДА в Git/GitHub.
- Секреты хранятся вне репозитория: `%USERPROFILE%\.ais-secrets\opencode\...` (OpenCode) и `config\.local_secrets.json` (проектные модули).
- В конфигурациях — только подстановки `{file:...}`, без значений.
