# Правило: Сервис ЭКСТРА

## Назначение

Однодневный экстренный режим, разрешающий LLM выполнять SELECT-запросы к БД.

**Спецификация:** `docs/services/extra.md`

## Краткое правило

| Параметр | Значение |
|----------|----------|
| Длительность | Один день (дата объявляется явно) |
| Разрешённые команды | **ТОЛЬКО** `SELECT` |
| Запрещённые команды | INSERT, UPDATE, DELETE, CREATE, ALTER, DROP, EXEC и любые другие |

## Ограничения данных

| Категория | Правило |
|-----------|---------|
| Имена, документы | **ЗАПРЕЩЕНО** выводить |
| Номера полисов/договоров | **ЗАПРЕЩЕНО** выводить |
| Суммы | **ЗАПРЕЩЕНО** выводить |
| Адреса, телефоны, email | **ЗАПРЕЩЕНО** выводить |
| Текстовые поля | Не более 10 символов (крайний случай) |
| Разрешённые поля | ID, коды, статусы, ссылки, технические поля |

## Назначение использования

- Анализ требований ТЗ
- Поиск решений выполнения требований ТЗ
- Только когда **иначе не обойтись** и время критически не хватает
