# rules/index.md — Центральный индекс файлов правил AIS Release Preparation

## Назначение
Этот файл содержит ссылки на все файлы правил проекта. При смене ИИ-модели достаточно прочитать этот файл для получения полного контекста проекта.

| Файл | Тип правил | Описание |

## Как использовать
1. Прочитать этот файл для получения обзора
2. Прочитать relevant файлы правил по типу задачи
3. При обнаружении нового бага — добавить запись в соответствующий файл правил
4. Обновить этот индекс при добавлении новых файлов правил
